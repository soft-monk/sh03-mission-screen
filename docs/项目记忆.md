## 1. 项目概况

- 纯静态 HTML + CSS + 原生 JS + MapLibre GL，**无构建、无 npm**；本地 `node serve.mjs`。
- 单例地图：`MapViewShared(host)` 跨场景复用，图元用 `mv.polygon / path / tracks / symbols / beam / fan / cover / label`。
- 主流程：SH-03 选场景 → SH-04 任务 → SH-05 方案 → SH-06 场景作战（场景一/二各一套）。
- 场景配置在 `data/scenarios.js`；`window.APP_STATE` 保存 `scenarioId / flow / aiMessages`。

## 5. 踩过的坑（别再犯）

1. **SAR 覆盖自检方向写反**：条带在航路**西侧**，判定要用 `dx ∈ [−10000, −8000]`。
2. **SAR 条带接缝**：相邻条带边界上的 1 格宽缝隙要留 120 m 容差，否则"看着扫到但没算"。
3. **光电边界窄条**：最外腿离边界太近会落进 2 km 盲区，必须钉在 1.3 km。
4. **四叉树切格会被说"划分不对"**：用户要的是**规则网格**（大格统一尺寸、城区大格切 2×2），不要混排尺寸。
5. **卫星截图判读**：先按任务区中心/边长对齐坐标再判城区，别把整张截图当任务区；分类器别把浅海当城区。
6. **传感器"进区就开机"是错的**：要到位才开机。
7. **目标命名不统一**会被打回：严格照场景二（编号 3 位 + 名称、地图标签加（疑似））。
8. **右侧目标卡片"点不动"**：场景一缺 `.s6-tb*` 样式与点击绑定时，卡片既没样式也不能展开。
9. **不要用 PowerShell 改中文文件**；用 `write/edit` 工具或 Node 脚本。
