# 公共时间轴 SH-01 ～ SH-03

> 三个场景完全共用这一段。数据来源：`js/timeline.js`（屏表 / 等待点）、`js/main.js`（切屏与播放控制）、`scenes/s01-boot.js`、`scenes/s02-selfcheck.js`、`scenes/s03-situation.js`。
> 时间一律为**全局秒**（从播片起点算），括号里的「屏内秒」是该屏自己的 `t`。

## 概览

| 屏号 | 起点 | 终点 | 时长 | 章节 | 标题 |
|---|---|---|---|---|---|
| SH-01 | 0 s | 6 s | 6 s | 启动 | 启动加载 |
| SH-02 | 6 s | 14 s | 8 s | 启动 | 自检校验 |
| SH-03 | 14 s | 26 s | 12 s | 集结 | 任务态势主界面 |
| — | **26 s 起进入所选场景分支** | | | | |

公共前缀在三场景的时间点**完全一致**：`data/flows.js` 直接复用 `js/timeline.js` 的 SH-01~03 三项，任何场景都不会改动这段。

## SH-03 任务态势主界面（14 – 26 s）

**这一屏不创建地图实例。** 背景是静态底图 `assets/img/basemap.jpg` + 暗角，不加载任何瓦片、不创建 MapLibre 实例。

| 全局秒 | 事件 |
|---|---|
| 14.0 | 切到 SH-03；`onShow` 里清空 `APP_STATE.scenarioId` 与 `flow`，并清掉地图上的区域图元 |
| 14.0 | 一次性显示：左菜单 6 项、工具栏 7 项、右上资源概况、比例尺、坐标、底部状态栏、麦克风按钮 |
| 14.0 | 三张场景卡与提示条常显（不依赖时间淡入） |
| **25.5** | **等待点**：全局暂停，等用户点卡片（`holds: { t: 25.5, prompt: "请选择任务场景" }`） |

**固定显示文字**

| 位置 | 文字 |
|---|---|
| 顶部品牌 | 智能任务管理系统 |
| 提示条 | 请选择任务场景 |
| 卡片 1 | 场景一 / 敏捷拒止布控 |
| 卡片 2 | 场景二 / 区域封控 |
| 卡片 3 | 场景三 / 要点防护 |
| 左菜单 | 态势、任务、目标、资源、告警、设置 |
| 工具栏 | 浏览、+ 新建、量算、场景、计划、图层、复位 |
| 状态栏 | 系统状态：就绪 / 无人机状态：在线 / 数据链路：稳定 / 定位状态：正常 / AI决策引擎：就绪 / 安全状态：安全 |

**业务图元**：任务区、目标区、禁飞区、集结区、标签、无人机 —— 选择场景之前**全部不显示**。

### 点击场景卡后的动作顺序

| 步骤 | 动作 |
|---|---|
| 1 | 写入 `APP_STATE.scenarioId = 卡片id`、`APP_STATE.flow = 该场景 flow` |
| 2 | `resetScenarioAudio()` 停掉上一轮语音；清空 `aiMessages` |
| 3 | `PLAYER.setFlow(id)`：切换成该场景的时间轴表、重建 HUD 章节条、更新结束卡文案 |
| 4 | 场景二：在屏幕外容器 `#mapwarm` 里**预先建好地图**；场景一/三 不建地图 |
| 5 | `PLAYER.lockBack()` → 之后所有回退入口失效（不能倒回 SH-03） |
| 6 | 620 ms 后 `seek(26)` + `play()`，进入 SH-04 |
